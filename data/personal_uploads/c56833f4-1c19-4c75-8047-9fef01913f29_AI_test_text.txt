第一部分：技术说明与长文本理解
============================================

人工智能（Artificial Intelligence，简称AI）是计算机科学的一个重要分支，旨在研究、开发用于模拟、延伸和扩展人类智能的理论、方法、技术及应用系统。自20世纪50年代诞生以来，人工智能经历了多次发展浪潮，从早期的符号主义到连接主义，再到如今的深度学习时代，每一次技术突破都带来了新的应用场景和可能性。

深度学习（Deep Learning）是机器学习的一个子领域，其核心思想是通过构建多层神经网络模型，让计算机自动从大量数据中学习特征表示。与传统的机器学习方法相比，深度学习在图像识别、自然语言处理、语音识别等领域取得了突破性进展。例如，在图像分类任务中，卷积神经网络（CNN）能够自动提取图像的层次化特征，从边缘、纹理到复杂的物体部件，最终实现对图像内容的准确识别。

自然语言处理（Natural Language Processing，NLP）是人工智能的另一个重要方向，研究如何让计算机理解、处理和生成人类语言。近年来，基于Transformer架构的大语言模型（Large Language Model，LLM）如GPT系列、BERT等，在文本生成、机器翻译、问答系统等方面展现了惊人的能力。这些模型通过在海量文本数据上进行预训练，学习到了丰富的语言知识和世界知识，能够通过微调或提示工程适应各种下游任务。

大语言模型的训练通常分为两个阶段：预训练（Pre-training）和微调（Fine-tuning）。预训练阶段，模型在大规模无标注文本上进行自监督学习，学习通用的语言表示；微调阶段，模型在特定任务的标注数据上进行有监督学习，使其适应具体的应用场景。此外，近年来还出现了基于人类反馈的强化学习（RLHF）技术，通过让人类评估模型输出并据此优化模型，显著提升了模型生成内容的质量和安全性。

def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quick_sort(left) + middle + quick_sort(right)

test_array = [64, 34, 25, 12, 22, 11, 90]
print(f"原始数组: {test_array}")
print(f"排序结果: {quick_sort(test_array)}")

问题二：数学计算
某工厂生产一种产品，固定成本为5000元，每生产一件产品的变动成本为20元。产品的售价为每件50元。请问：
(1) 盈亏平衡点是多少件？
(2) 如果要实现10000元的利润，需要销售多少件？

问题三：数据分析
某电商平台上个月共售出商品12000件，其中：
- 电子产品占35%，平均单价800元
- 服装配饰占28%，平均单价200元
- 家居用品占22%，平均单价350元
- 其他类别占15%，平均单价150元

请计算：
(1) 上个月总销售额是多少？
(2) 哪类商品对总销售额贡献最大？
(3) 如果电子产品销量增长20%，其他不变，总销售额增长多少百分比？
